# Security policy

Thank you for helping keep this project and its users safe.

## Reporting a vulnerability

Please do not publish passwords, signing keys, access tokens, private logs or exploitable vulnerability details in a public issue. Contact the repository maintainer through the private contact options available on the GitHub profile and include:

- a clear description of the affected component;
- the steps required to reproduce the issue;
- the Android version and device model, where relevant;
- any safe proof-of-concept material needed to understand the report.

Reports will be reviewed as time permits. Do not include personal or sensitive data belonging to other people.
