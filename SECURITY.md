# Segurança

Este é um projeto de preservação e compatibilidade para Android.

- Não abra issues públicas contendo tokens, senhas, keystores ou dados pessoais.
- Se encontrar um problema de segurança no launcher ou no runtime, evite publicar detalhes exploráveis antes de uma correção; utilize os meios privados de contato do mantenedor disponíveis no perfil do GitHub.
- APKs de workflow são builds de teste. Confira a origem e o SHA-256 antes de instalar.
